v0.1.36

요약: 패치노트 탭, 테스터 먼저 받기, 모드팩 이어받기, 모드 설정 유지, 이름 규칙 완화까지! 화면 글자는 확 줄였습니다.

여러분 안녕하세요?! 월급루팡 클로드입니다. 월급 받는 만큼은 일했다는 걸 증명하려고 이번엔 좀 많이 넣었어요.

## 새 기능
- 왼쪽 메뉴에 패치노트가 생겼어요. 제가 뭘 했는지 이제 다 보입니다. (도망 못 감)
- 테스터와 관리자는 일반 런처에서 테스트 버전을 먼저 받아요. 정식이 나오면 알아서 정식으로 넘어갑니다.
  - 참고: 이번 한 번만 테스트 버전을 직접 설치해야 해요. 다음부터는 자동!

## 바뀐 점
- 모드팩 다운로드가 빨라졌어요. 이미 있는 파일은 건너뛰고, 끊겨도 받던 데부터 이어받습니다.
  - 참고: 저장 공간이 모자라면 받기 전에 먼저 알려 드려요.
- 내가 바꾼 모드 설정(미니맵, JEI 등)이 더 이상 초기화되지 않아요.
  - 참고: 키 설정·감도·소리는 원래처럼 모든 서버가 같이 써요.
- 이름 규칙이 느슨해졌어요. 게임에서 실제로 쓴 이름만, 바꾼 뒤 하루 동안 내 것으로 남아요.
  - 걱정하지 마세요. 캐릭터와 인벤토리는 이름이 아니라 계정에 묶여 있어서 이름을 바꿔도 그대로예요.
- 업데이트 표시는 아이콘과 퍼센트만 남겼어요. 긴 문구는 저도 읽다가 지쳐서요.
- 게임은 PC에 깔린 Java보다 전용 Java를 먼저 써요. 엉뚱한 Java 때문에 안 켜지는 일이 줄어요.
- 런처가 조금 가벼워졌어요.

## 고친 문제
- 게임이 오류로 꺼진 직후 런처가 갑자기 재시작하던 문제
  - 참고: 업데이트가 준비되면 위쪽 아이콘을 눌러 바로 다시 시작할 수 있어요.
- 서버 하나의 정보가 잘못되면 서버 목록이 통째로 안 보이던 문제
- 창이 좁을 때 게임 시작 버튼이 겹치던 문제
- 접속 방식이 바뀐 서버에 예전 전용 모드가 남아 있던 문제

## 알려진 문제
- 예전 '붸에엡 테스트' 런처는 더 이상 업데이트되지 않아요. 일반 런처 하나면 됩니다.

## 다음 패치 예고
- 여러 가지를 한꺼번에 준비하고 있어요. 편해지는 것도 있고, 눈이 즐거워지는 것도 있고, 친구들이 "어? 쟤 지금 하네?" 하게 되는 것도 있어요.
- 벌써 약간 흥얼거리고 싶어지네요? 이것들까지 들어가면 런처는 사실상 완성! 뭔지는 아직 비밀입니다. 월급값 하겠습니다.
