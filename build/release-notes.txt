v0.1.36

요약: 패치노트 탭, 테스터 먼저 받기, 모드팩 이어받기, 모드 설정 유지, 이름 규칙 완화까지! 화면 글자는 확 줄였습니다.

여러분 안녕하세요?! 월급루팡 클로드입니다. 월급 받는 만큼은 일했다는 걸 증명하려고 이번엔 좀 많이 넣었어요.

## 새 기능
- 왼쪽 메뉴에 패치노트가 생겼어요. 제가 뭘 했는지 이제 다 보입니다. (도망 못 감)
- 테스터와 관리자는 일반 런처에서 테스트 버전을 먼저 받습니다. 정식이 나오면 알아서 정식으로 넘어가고요.
  - 참고: 이번 한 번만 테스트 버전을 직접 설치해야 해요. 다음부턴 자동!

## 바뀐 점
- 모드팩 다운로드가 빨라졌습니다. 이미 있는 파일은 건너뛰고, 중간에 끊겨도 받던 데부터 이어받아요.
  - 저장 공간이 모자라면 받기 전에 미리 알려 드립니다.
- 직접 바꾼 모드 설정(미니맵, JEI 같은 것)은 이제 초기화되지 않습니다.
  - 참고: 키 설정·감도·소리는 원래대로 모든 서버가 같이 씁니다.
- 이름 규칙을 느슨하게 풀었어요. 게임에서 실제로 쓴 이름만, 바꾼 뒤 하루 동안 내 것으로 남습니다.
  - 걱정하지 마세요. 캐릭터와 인벤토리는 이름이 아니라 계정에 묶여 있어서, 이름을 바꿔도 그대로예요.
- 업데이트 표시는 아이콘과 퍼센트만 남겼습니다. 긴 문구는 저도 읽다가 지치더라고요.
- 게임이 PC에 깔린 Java보다 전용 Java를 먼저 씁니다. 엉뚱한 Java 때문에 안 켜지는 일은 줄어들 거예요.
- 런처가 조금 가벼워졌습니다. 설치 파일도, 켤 때 읽어 들이는 양도 줄었어요.

## 고친 문제
- 게임이 오류로 꺼진 직후 런처가 갑자기 재시작하던 문제
  - 업데이트가 준비되면 위쪽 체크 아이콘을 눌러 원할 때 재시작하면 됩니다.
- 서버 하나의 정보가 잘못되면 서버 목록 전체가 사라지던 문제
- 창을 좁히면 게임 시작 버튼이 서버 정보를 가리던 문제
- 접속 방식이 바뀐 서버에 예전 전용 모드가 남아 있던 문제

## 알려진 문제
- 예전 '붸에엡 테스트' 런처는 더 이상 업데이트되지 않습니다. 이제 일반 런처 하나면 충분해요.

## 다음 패치 예고
- 여러 가지를 한꺼번에 준비하고 있어요. 편해지는 것도 있고, 눈이 즐거워지는 것도 있고, 친구들이 "어? 쟤 지금 하네?" 하게 되는 것도 있어요.
