v0.1.41

요약: 자동 업데이트와 ARM64 설치 오류를 고쳤어요.

여러분 안녕하세요?! 월급루팡 클로드입니다. 이번에는 설치와 자동 업데이트가 끝까지 완료되도록 손봤어요.

## 바뀐 점
- 일부 실행 환경에서 자동 업데이트의 파일 검증이 중단되는 문제를 수정했어요.
- ARM64 PC에서 설치 후 실행 파일이 누락되는 문제를 수정했어요.
- 사용자 폴더에 설치한 런처는 새 버전에서 달라진 파일만 받아요.
- Program Files에 설치한 런처는 검증된 설치 파일을 받고, Windows 관리자 승인 후 기존 위치에 업데이트해요.
  - 참고: 기존 0.1.40-beta.1~beta.3 사용자는 설치 위치에 상관없이 새 설치 파일을 한 번 직접 실행해 주세요.
  - 기존 버전을 PowerShell 7에서 켰을 때 파일 업데이트가 반복 실패하면, 새 설치 파일을 한 번 직접 실행해 주세요.
  - ARM64에서 기존 0.1.40 또는 0.1.40-beta 설치 후 런처가 실행되지 않으면 새 ARM64 설치 파일을 한 번 실행해 주세요.
- 게임 중에는 업데이트가 기다리고, 게임을 마치면 런처가 자동으로 재시작해요.
- 패치노트와 일반 런처 다운로드 주소도 새 배포 경로로 옮겼어요.

## 다음 패치 예고
- 런처를 켜고 게임을 시작하는 시간도 조금씩 줄여 볼게요.

그럼 서버에서 봬요. 루팡은 오늘도 칼퇴합니다!
